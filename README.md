# 運動目標・実績共有アプリ 簡易デモ

医師が決めた運動の目標と内容を、患者さん・看護師・医師で共有するアプリの、動作確認用の簡易HTMLデモです。
画面の例と動かし方を確認するためのもので、架空のデータだけで動きます。

**公開URL**: https://tsubasagit.github.io/kagawa-exercise-record-demo/

## 方針

医学的な判断は医師が行い、アプリは「記録・計算・表示・共有」だけを担当します。

- 目標と運動内容は、医師が入力した内容をそのまま表示する（アプリは選ばない・変えない）
- InBody などの測定値は、取り込んで表示するだけ。運動の選択には使わない
- 計算は引き算と割り算だけ（目標との差、今週の達成率）
- 「改善」「悪化」「正常」などの評価の言葉や、基準値による色分けはしない
- 通知は事実だけ（例：「3日間、運動記録がありません」）

## 画面

| 画面 | ファイル | 内容 |
|---|---|---|
| 入口 | `index.html` | 3つの画面への入口と、しないことの一覧 |
| 医師用 | `doctor.html` | 目標（項目・値）と運動内容の設定、測定値の取り込み（CSV または手入力）、設定の履歴 |
| 患者さん用 | `patient.html` | 医師が設定した目標と運動内容、目標との差、今週の達成率、運動の記録の入力 |
| 看護師・医師用 | `research.html` | 患者さんごとの目標・現在値・今週の実施、記録の一覧、Excel 出力（見るだけ） |
| 共通処理 | `common.js` | 保存、目標との比較、今週の集計、デモデータ |
| 画面写真 | `画面写真/` | 各画面の例（デモデータ） |

## 動かし方

ビルド不要。`index.html` をブラウザで開く。入口の「デモデータで見る」から、架空の研究ID（K-001〜K-003）の例が見られる。

- データはこの端末のブラウザ（localStorage）にだけ保存される
- Excel 出力は cdnjs の SheetJS を読むため、ネット接続が必要（つながらないときは CSV で出力）
- 測定値の CSV は、1行目に「測定日（日付）」「体脂肪率」「体重」「骨格筋量」などの見出しがある形を仮に読み込める。実際の InBody の出力形式は、確認して合わせる

## 本番への置き換え

- 保存先は Firebase に置き換える。研究IDで仮名化し、氏名は持たない
- 医師用・看護師用・患者さん用を、ログインと役割で分ける（看護師は閲覧のみ）
- 医療機器に当たるかどうかは、アプリ全体の目的と機能で決まる。仕様を確定する前に、所管の窓口へ確認する
