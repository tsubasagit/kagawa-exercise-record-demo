# 運動記録アプリ 簡易デモ

脂肪肝改善アプリのうち「運動の記録」だけを取り出した、動作確認用の簡易HTMLデモ（2026-10-30 作成）。非公開。

- `index.html` 入口
- `patient.html` 患者さん用: 運動の種類・時間などの入力
- `research.html` 研究用: 一覧表示と Excel 出力
- `common.js` 両画面で共有する処理（保存・運動の種類の定義）
- `画面写真/` 画面の例

## 動かし方

ビルド不要。`index.html` をブラウザで開く。データはこの端末のブラウザ（localStorage）にだけ保存される。Excel 出力は cdnjs の SheetJS を読むためネット接続が必要。

## 本番への置き換え

保存先は Firebase に置き換える予定。研究IDで仮名化し、氏名は持たない。
